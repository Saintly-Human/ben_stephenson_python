# Morse Code Translator

## 📝 Description
This program converts a text message entered by the user into standard **Morse Code**.

It maps letters (A–Z) and digits (0–9) to their corresponding sequence of dots (`.`) and dashes (`-`). Standard spaces between words are preserved, while unsupported characters are ignored.

## 💡 **Example Usage**

### Input:
```text
Hello World 123
```

### Output:
```text
.... . .-.. .-.. --- .-- --- .-. .-.. -.. .---- ..--- ...--
```
